# Simple Interest Calculator

A simple Bash command-line calculator that computes **simple interest** from user input.

## Description

This project asks the user for three values and calculates the simple interest:

- **Principal**: the initial amount of money
- **Rate of interest**: the yearly interest rate, in percent
- **Time period**: the duration, in years

## Formula

Simple Interest = (Principal x Rate x Time) / 100

## Usage

Run the script from a terminal with `bash simple-interest.sh`, then enter the principal, the rate of interest and the time period when asked.

## Example

Principal = 1000, Rate = 5, Time = 2

Simple Interest = (1000 x 5 x 2) / 100 = 100
